Network Policy Loopholes

Identified configuration gaps that allow perimeter filtering controls to be bypassed

Vulnerability Risk Level Details & Operational Impact
Microsoft Edge Add-ons Store Open microsoftedge.microsoft.com/addons High Access to the official Edge extension repository is unblocked. Users can install browser proxy extensions directly to bypass captive portal limits without needing administrator credentials on the computer.
Chrome & Mozilla Add-on Hubs Accessible chromewebstore.google.com / addons.mozilla.org High Allows users on alternative browsers to add one-click proxy utilities that wrap outbound web traffic in encrypted HTTPS tunnels, sidestepping Sophos web category restrictions.
Encrypted DNS Enabled in Browsers DNS-over-HTTPS (DoH) High Modern browsers send encrypted domain name queries directly to public resolvers (such as Cloudflare or Google). This hides visited domains from local gateway monitors unless public DoH servers are restricted.
Public Web Translators Operating as Proxies translate.google.com / bing.com/translator Medium Users can submit restricted URLs into web translation portals. The third-party server fetches and displays the page content within its own allowed frame.
Dual-Stack IPv6 Bypass Unrestricted IPv6 Network Interface Medium If web categorization rules are bound strictly to IPv4 routing, destinations reachable over native IPv6 connections may bypass captive portal policies entirely.
Public Web Snapshot & Archive Mirrors archive.org / webcache.googleusercontent.com Low Enables browsing cached snapshots of restricted research or academic materials without establishing a direct link to the original blocked server.
Administrator Advisory: Browser-based VPNs function as encrypted TLS web proxies over port 443. While blocking the domains and fallback nodes listed below prevents tunnel initialization, complete mitigation requires disabling extension installation centrally.
